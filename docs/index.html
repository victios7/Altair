Storage tiers

La memoria no se improvisa: se declara

En Altair el nivel de almacenamiento forma parte del lenguaje. Eliges el tier al crear el valor y puedes moverlo después con orbit, prefer y weight.

ram Rápido, volátil. Estado caliente del programa.
cache Intermedio. Reutilización sin persistir siempre.
disk Persistente. Sobrevive al reinicio del proceso.
temp Temporal. Datos de corta vida.
p#

Memoria contigua

Cuando necesitas control fino: alloc, p#read, p#write sobre bloques planos. Ideal para buffers, tablas de pesos, estructuras densas y herramientas de sistemas.

& | ^ << >>

Operadores bit a bit

AND, OR, XOR, desplazamientos y máscaras en la expresión normal del lenguaje. Pensado para flags, protocolos, ensambladores y lógica de bajo nivel sin salir a C.

Características

De lo esencial al binario nativo

01

Storage tiers

ram, disk, cache, temp con orbit, prefer y weight. La política de datos es sintaxis, no convención.

02

Memoria p#

Bloques contiguos con alloc, lectura y escritura por offset. Control cercano a C con tipos de Altair.

03

Bit a bit

Operadores & | ^ << >> integrados para flags, packing y código de sistemas.

04

Sintaxis clara

Variables, funciones, texto y listas sin ceremonia. Productivo para parsers, CLIs y herramientas.

05

Compila a nativo

.at → C → gcc → binario. Un ejecutable por programa en Windows, Linux o macOS.

06

HTTP y jobs

Opcional: listen/route, sesiones y job … every cuando el programa necesita servicio, no solo lógica.

p#w bloque = alloc(256)

Instalación

El instalador añade altairc al sistema. No necesitas toolchain aparte en Windows.

Descarga el instalador o paquete

Windows (.exe), Linux (.deb) o macOS (.pkg) desde las Releases en GitHub.

Instálalo

Preguntas frecuentes

Sobre Altair Lang

Q

¿Qué es Altair Lang?

Un lenguaje compilado a C nativo. Destaca por storage tiers (ram, disk, cache, temp), memoria p#, operadores bit a bit y un binario por programa en Windows, Linux y macOS.

Q

¿Cómo se controla la memoria?

Declaras el tier al crear la variable y puedes moverla con orbit. Para bloques densos usas p# (alloc, p#read, p#write).

Q

¿Es lo mismo que Altair BASIC?

No. Altair BASIC fue el intérprete de Microsoft de 1975. Altair Lang es un proyecto distinto y actual.

Q

¿Cómo se compila?

altairc programa.at -o programa genera el binario nativo. Guía completa en guia.html.

Q

¿Es gratis?

Sí, licencia MIT. Código e instaladores en GitHub.
