La memoria se declara, no se improvisa.

Altair es un lenguaje de nivel medio-bajo: cada valor elige dónde vive (ram, disk, cache, temp), los punteros llevan tipo con p#, y altairc genera un binario nativo sin runtime externo.

Storage tiers

Dónde vive cada valor forma parte del lenguaje

Declaras el tier al crear la variable. Puedes añadir weight, expire, o usar bloques prefer y orbit cuando el almacenamiento debe ser dinámico.

ramRápido, volátil
cacheDisco con TTL
diskPersiste entre ejecuciones
tempRAM; se borra al liberar
autoLo elige el runtime
ORBIT · MIGRATE

Estados de almacenamiento

Defines ciclos de vida con orbit y cambias de estado con migrate (por número o por nombre). Cada estado tiene su tier.

PREFER · WEIGHT · EXPIRE

Prioridad y caducidad

prefer ordena fallbacks de storage. weight marca prioridad. expire define TTL en variables cache o disk.

Características

Control fino, sintaxis clara, binario nativo

01

Storage tiers

ram, disk, cache, temp, auto en la declaración. Opcionalmente weight y expire.

02

Punteros p#

p#Tipo nombre declara un puntero tipado. alloc, p#read, p#write, p#free.

03

Bit a bit

Operadores & | ^ ~ << >> sobre numeric para flags y packing.

04

Matemáticas m#

m#sqrt, m#exp, m#tanh, m#pow y el resto del runtime matemático.

05

Compila a nativo

Pipeline .at → C → binario. Un ejecutable por programa en Windows, Linux o macOS.

06

HTTP y jobs

Opcional: listen / route, sesiones y job … every cuando el programa es un servicio.

Ejemplo

Sintaxis real del lenguaje

Declaración de storage, orbit, prefer, puntero tipado y bits — tal como los espera el compilador.

altair.doc;
  name = "DemoMemoria"
  version = "1.0"
create altair.doc

numeric contador = 0 ram
text ruta = "estado.dat" disk
numeric hot = 0 ram weight 800
expire 1h text ticket = "abc" cache

numeric sesion = 0 orbit;
  1 = nueva temp
  2 = activa ram
  3 = guardada disk
break

sesion migrate 2
sesion = 100
sesion migrate guardada

numeric resultado = 0 prefer;
  1 = ram
  2 = cache
  3 = disk
break

p#buf bloque = alloc(256)
p#write(bloque, 0, 255)
numeric v = p#read(bloque, 0)
p#free(bloque)

numeric flags = 0 ram
flags = flags | 1
flags = flags << 2
flags = flags & 255

numeric r = m#sqrt(16) ram
log "v=" + v + " flags=" + flags + " r=" + r

FAQ

Preguntas frecuentes

Q

¿Qué es Altair Lang?

Un lenguaje compilado a C nativo. Destaca por storage tiers, punteros p#Tipo, orbit/prefer/migrate, matemáticas m# y operadores bit a bit.

Q

¿Cómo se declara el almacenamiento?

numeric x = 0 ram. Opciones: disk, cache, temp, auto, más weight, expire, bloques prefer y orbit, y migrate para cambiar de estado.

Q

¿Qué es release?

release variable elimina la variable del registro y libera su memoria (no solo la pone a cero). Útil en bucles y datos temp.

Q

¿Es lo mismo que Altair BASIC?

No. Altair BASIC fue el intérprete de Microsoft de 1975. Altair Lang es un proyecto distinto y actual.

Q

¿Cómo se compila y es gratis?

altairc programa.at -o programa. Licencia MIT; instaladores en GitHub. Guía en guia.html.
