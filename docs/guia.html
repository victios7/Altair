Versión del lenguaje: 1.7vB Compilador: altairc 1.7 (compiler@version = "1.7") Fuente: código C del compilador y runtime (lexer, parser, sema, codegen, altair_rt)

Documenta todo lo que el binario implementa. No inventa sintaxis. Los stubs y lo previsto para otra versión se marcan.

**m# (matemáticas):** keyword m, parseo y _fn_* math están en el código 1.7. Se documentan aquí; la API estable de lenguaje se anuncia como Altair 1.7.5 Math (próximamente).

1. Pipeline

.at → lexer → parser → sema → codegen → .c → gcc/clang/MinGW → binario

Runtime: runtime/altair_rt.c se compila junto al C generado. Sin VM.

2. Cabecera de programa

Opcional:

altair.doc;
    name = MyApp
    version = 1.0.0
    author = "Autor"
create altair.doc

Campos: name, version, author. El resto del fichero es el cuerpo.

3. Comentarios

/ al inicio de línea (tras espacios), seguido de espacio/tab/fin de línea/letra → comentario hasta EOL. El lexer no confunde / de división cuando el token anterior fue un valor.

4. Declaración de variables

Forma que documentamos (declaración por tipo):

<tipo> <nombre> [= expresión] [storage | orbit | prefer] [cualificadores] [persistencia]
numeric count ram = 0
text name disk = "mundo"
bool ok ram = true
list items ram
token code temp = "ABC"
file f ram = open("a.txt")

Storage, orbit, prefer y cualificadores se reconocen tras el nombre / inicializador según el parser.

Storage

KeywordRuntimeEfecto
ramALT_RAMMemoria de proceso
diskALT_DISKPersistente bajo ~/.altair/<programa>/disk/
cacheALT_CACHEPersistente con TTL opcional
tempALT_TEMPSe limpia al liberar
autoALT_AUTOEl runtime elige

Si no se escribe storage, el parser pone STOR_AUTO (no es error).

Cualificadores

  • const — no reasignable (ALT0007)
  • expire=<dur> — 30s, 5m, 2h, …
  • weight=<n> — entero ≥ 0
numeric pi const ram = 3.14159
text sess cache expire=30m = ""

Asignación

count = count + 1
count += 10
count -= 1
count *= 2
count /= 2
count %= 3

release

text buf ram = "x"
release buf

AST también tiene tipos gráficos: imagen, sonido, música, color (raylib).

Indexado y longitud

text s ram = "abc"
log s[0]
log length(s)

Fuera de rango → ALT0013.

tonum

text t ram = "42"
numeric v ram = tonum(t)

0 + t concatena (queda texto), no convierte.

6. Operadores

Aritméticos: + - * / % y - unario. Comparación: == != < > <= >= Lógicos: && || ! Bitwise: & | ^ ~ << >> (solo numeric; helpers altair_band … altair_shr) Compuestos: += -= *= /= %=

Precedencia (mayor a menor): unarios → * / % → + - → shifts → & → ^ → | → relacionales → igualdad → && → ||.

7. Control de flujo

Bloques cerrados con break.

if x > 0;
    log "pos"
break
elif x == 0;
    log "cero"
break
else;
    log "neg"
break

numeric i ram = 0
while i < 10;
    i += 1
break

repeat 3 times;
    log "h"
break

forever;
    wait 1s
break

list xs ram = [1, 2]
foreach x in xs;
    log x
break

exit
wait 2s

8. Funciones

fun greet name text;
    log "Hola " + name
    return name
break

fun add -> numeric numeric a, numeric b;
    return a + b
break

greet("Ana")
numeric r ram = add(1, 2)

Codegen: _fn_<nombre>. Recursión permitida.

9. Clases y objetos

class Point;
    numeric x ram = 0
    numeric y ram = 0
    fun dist;
        return x * x + y * y
    break
break

create object Point as p
p.x = 3
log p.dist()

Campo inexistente al leer → ALT0014.

15. Introspección

system@: time, random, pid, hostname, username, os, memory, diskfree compiler@: version ("1.7"), name, build, architecture program@: name, version, author variable: system@storage(v), weight, type, size, value, orbit

Desconocida → ALT0011.

16. token

17. orbit, prefer, migrate

numeric d orbit 1 "hot" ram, 2 "warm" disk = 0
migrate d as "warm"
migrate d as 2

text s prefer ram, cache, disk = ""

prefer vacío → ALT0006. Estado orbit inválido → ALT0012.

18. Servidor HTTP

listen 8080;
    route "GET" "/";
        respond.text("ok")
    break
break

Sockets propios, un hilo.

Rutas

Métodos: GET POST PUT DELETE PATCH *. Params :id → param("id"). header, body, respond.text, respond.json, respond.status, stop.

Middleware

middleware auth;
    text t ram = header("Authorization")
    if t == "";
        respond.status(401)
        stop
    break
break

Rate limit

rate_limit N per_minute o per_second → 429 al exceder.

Health / metrics / jobs / shutdown

health "/health";
    check "db" -> true
break

metrics "/metrics";

job clean every 5m;
    log "c"
break

schedule beat every 30s;
    log "b"
break

on_shutdown;
    log "bye"
break

Sesiones

session tok expires 30m;

session_get / session_set en runtime.

Config

config;
    env("PORT") default "8080"
    env("SECRET") required
break

required sin env → ALT0015.

db_pool

db_pool db = connect("postgres://…") max 20

Stub: se parsea; no hay cliente SQL en el runtime.

19. Gráficos (raylib)

link graphics raylib

Activa include/link a libs/raylib/<os>/ o sistema.

window
    title = "App"
    width = 800
    height = 600
    fps = 60
create window

loop
    clear skyblue
    draw text
        content = "Hola"
        x = 10
        y = 10
        size = 24
        color = white
    create draw
    draw rect
        x = 100
        y = 100
        width = 50
        height = 50
        color = red
    create draw
    draw circle
        x = 200
        y = 200
        radius = 30
        color = gold
    create draw
break

draw kinds en codegen: text, rect/rectangle, circle, line, line_thick/thick_line, triangle, pixel, image/texture.

Audio/imagen: image, sound, music, play (LoadTexture/Sound/MusicStream, PlaySound). stop/pause parciales.

Input: key → IsKeyDown; cursor (hidden/show/default/crosshair/hand/resize).

Widgets UI: keywords existen; button/timer/animate con codegen limitado; menu/dialog/scene/goto/popup/canvas/column/row/grid ≈ stub.

21. Punteros p#

p es keyword reservada.

p#node n = alloc(64)
p#write(n, 0, 42)
numeric v ram = p#read(n, 0)
log p#bytes(n)
log p#null(n)
p#free(n)

Slots de 8 bytes. p#write y p#free mutan por referencia. También en runtime: ptr_alloc, ptr_free, ptr_is_null.

22. Persistencia nombre.archivo

numeric coins ram = 120 player.coins
text name ram = "A" player.name

Carpeta variables/. Prefijos de tipo N/T/B. Carga al declarar; guarda al asignar y al salir.

23. data

data Save disk;
    numeric coins = 120
    text name = "A"
data create

data Save migrate cache

Ficheros variables/<Nombre>.<var>.<lugar>. migrate hace rename; el path compilado de cada var no cambia en caliente.
